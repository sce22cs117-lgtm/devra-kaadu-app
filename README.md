# Devra Kaadu 🌿

Devra Kaadu (Sacred Grove) is an Android application designed to help users explore, identify, and protect sacred groves. The app provides a directory of groves, a scanning feature for plants, and an alert system for environmental concerns.

## Features

- **Grove Directory**: Browse a list of sacred groves with details about their cultural and scientific importance.
- **Plant Scanner**: Identify sacred plants and learn about their significance.
- **Alert System**: Report and view alerts related to the preservation of these ecological hotspots.
- **Detail View**: In-depth information about specific groves, including myths and scientific facts.

## Tech Stack

- **Language**: Kotlin
- **UI Framework**: Jetpack Compose
- **Navigation**: Compose Navigation
- **Architecture**: Modern Android Architecture components

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/sce22cs117-lgtm/devra-kaadu-app.git
   ```
2. Open the project in Android Studio.
3. Build and run the app on an emulator or a physical device.

## Project Structure

- `screens/`: Contains the UI components for different screens (Home, Map, Scan, Alert, Detail).
- `data/`: Sample data and data models for the groves.
- `model/`: Data classes used across the application.

## Security & Privacy

- All private API keys and sensitive configuration are excluded from version control.
- Uses `local.properties` for environment-specific configurations.
